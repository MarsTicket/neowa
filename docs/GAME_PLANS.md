## 51. 숫자 합치기 (`merge`)
- **종류/색**: 퍼즐 · `#ffb547` / rgb `255,181,71` / ink `#241400`
- **핵심 재미**: 같은 숫자가 부딪쳐 2배가 되는 쾌감, 판이 꽉 차기 직전의 긴장.
- **규칙**: 5열 세로 판(5×7). 아래에서 숫자 블록(2·4·8 중 무작위, 높은 숫자는 판 최대값의 1/8 이하)을 원하는 열로 **위쪽으로 쏘아 올림**. 블록은 위로 쌓이며, 상하좌우로 같은 숫자와 닿으면 합쳐져 2배(합쳐진 결과가 다시 이웃과 같으면 연쇄). 어떤 열이든 7칸이 차서 더 못 쏘면 끝.
- **다른 게임과 다른 점**: 미는 방식이 아니라 "열을 골라 쏘는" 방식 (2048류와 다름).
- **조작**: 터치 = 열 탭(또는 끌어서 열 고르고 떼기). 키보드 = ←→ 열 선택, Space 발사. 다음 블록 1개 미리보기.
- **난이도 곡선**: 판 최대값이 커질수록 나오는 블록 범위가 커짐. 512 도달마다 "2" 블록 한 줄 제거 보너스.
- **점수**: 합쳐질 때 결과값만큼 + 연쇄 배율(2연쇄 ×2, 3연쇄 ×3). maxScore 5,000,000.
- **HUD**: SCORE / MAX(최대 블록) / NEXT
- **연출**: 합쳐질 때 블록이 커졌다 작아지는 애니메이션, 값마다 색 다름(2 회색 → 2048 금색).
- **참고 코드**: `blocks.js`(격자·줄 지우기 연출), `gems.js`(연쇄 처리·낙하 애니메이션)
- **완료 조건**: 연쇄가 끝날 때까지 입력 잠금 / 같은 숫자 3개가 동시에 닿을 때도 한 번에 정상 처리 / 판이 차면 1초 뒤 종료.

## 52. 한글 단어 맞히기 (`hangul`)
- **종류/색**: 두뇌 · `#7dff9b` / `125,255,155` / `#04170a`
- **핵심 재미**: 자모 단위 힌트로 단어를 좁혀 가는 추리.
- **규칙**: 정답은 **2음절 한글 단어**. 자모로 풀면 보통 5~6칸(예: 사과 = ㅅㅏㄱㅗㅏ → 표기는 "ㅅ ㅏ ㄱ ㅘ"처럼 겹모음은 한 칸). 6번 안에 맞히기. 칸 색: 초록(자리까지 맞음), 노랑(있지만 다른 자리), 회색(없음).
- **단어 목록**: `docs/tools/games/hangul_words.js`에 **정답용 300개 이상**(쉬운 명사: 사과, 바다, 하늘…) + **입력 허용 단어 2,000개 이상**을 직접 작성. 비속어·고유명사·외래어 금지. 목록에 없는 단어 입력 시 "사전에 없는 단어" 흔들림.
- **모드**: ① 무한 모드(맞히면 다음 단어, 연속 기록), ② 오늘의 단어(날짜로 고정된 1개, `daily`와 연결 가능).
- **조작**: 화면 아래 자모 키패드(ㄱ~ㅎ, ㅏ~ㅣ, 지우기, 확인). 키보드 = 한글 입력이 OS마다 달라 불안정하므로 **2벌식 키 매핑을 직접 처리**(q=ㅂ, w=ㅈ … 영문 키 이벤트를 자모로 변환).
- **점수**: (7 − 시도 횟수) × 100 × 연속 배율. maxScore 300,000.
- **HUD**: SCORE / TRY x/6 / STREAK
- **참고 코드**: `baseball.js`(입력·판정·기록 목록 UI)
- **완료 조건**: 같은 자모가 여러 번 들어간 단어의 노랑/초록 판정이 정확(정답에 있는 개수만큼만 색칠) / 키패드에 자모별 최근 색 표시.

## 53. 미니 골프 (`golf`)
- **종류/색**: 액션 · `#7dff9b` / `125,255,155` / `#04170a`
- **핵심 재미**: 벽 반사를 계산해 한 번에 넣는 "홀인원".
- **규칙**: 위에서 내려다본 코스. 공을 당겨 쏘기(방향·세기). 9홀 1라운드. 홀마다 기준 타수(파). 장애물: 벽, 움직이는 막대, 모래(감속), 물(1벌타 후 직전 위치), 경사(일정 방향 힘), 순간이동 구멍.
- **코스 생성**: 손으로 만든 **코스 조각 20개**(JSON 배열, 선분·원 장애물 좌표)를 매 라운드 무작위 9개 선택 + 좌우 뒤집기 → 반복 플레이성.
- **조작**: 공 근처를 끌어 당기기(당긴 반대 방향으로 발사, 예상 경로 3개 점 표시). 키보드 = ←→ 방향, ↑↓ 세기, Space 발사.
- **물리**: 서브스텝 8, 선분 반사(`pinball.js`의 `collideSeg` 그대로 응용), 마찰 감속.
- **점수**: 홀마다 (파 − 타수 + 3) × 100, 홀인원 +500. 9홀 끝나면 종료. maxScore 20,000.
- **HUD**: SCORE / HOLE n/9 / STROKE
- **참고 코드**: `pinball.js`(선분 충돌), `archery.js`(당겨 쏘기)
- **완료 조건**: 공이 벽 사이에 끼어 멈추지 않음 / 공이 완전히 멈춘 뒤에만 다음 샷 / 10타 넘으면 자동으로 다음 홀(+기준 타수×2).

## 54. 떨어지는 블록 (`fall`)
- **종류/색**: 퍼즐 · `#5ee7ff` / `94,231,255` / `#03161c`
- **핵심 재미**: 줄을 여러 개 한 번에 지우는 손맛.
- **규칙**: 10×20 판. 4칸짜리 블록 7종이 위에서 떨어짐. 회전·좌우 이동·빠른 낙하·즉시 낙하. 가로 줄이 차면 지워짐. 위까지 차면 끝. 다음 블록 3개 미리보기, 보관(홀드) 1칸.
- **차별화(필수)**: 이름·색·연출을 독자적으로. 블록 모양은 일반적인 7종 테트로미노를 써도 되지만 **상표 이름·로고·음악 금지**.
- **조작**: 터치 = 좌우 스와이프 이동, 탭 회전, 아래로 스와이프 빠른 낙하, 아래로 빠르게 튕기면 즉시 낙하, 두 손가락 탭 홀드. 화면 아래 버튼 6개도 제공(←, →, 회전, 아래, 즉시, 홀드). 키보드 = ←→↓, ↑/X 회전, Space 즉시, C 홀드.
- **난이도 곡선**: 10줄마다 레벨+1, 낙하 속도 증가. 7종을 한 묶음씩 섞어 뽑기(같은 블록 연속 과다 방지).
- **점수**: 1/2/3/4줄 = 100/300/500/800 × 레벨. maxScore 10,000,000.
- **HUD**: SCORE / LEVEL / LINES
- **참고 코드**: `blocks.js`(격자·줄 삭제 연출), `snake.html`(방향 패드 `pad:true`)
- **완료 조건**: 벽 근처 회전 시 1칸 밀어서 회전 시도(벽 차기) / 바닥 닿은 뒤 0.5초 유예 / 위가 막히면 즉시 종료.

## 55. 한붓 그리기 (`paint`)
- **종류/색**: 퍼즐 · `#ff7aa8` / `255,122,168` / `#2a0515`
- **핵심 재미**: 모든 칸을 한 번씩만 지나는 길을 찾는 "아하!" 순간.
- **규칙**: 격자(5×5 → 8×8)에서 시작 칸부터 손가락을 떼지 않고 끌어 모든 빈칸을 정확히 한 번씩 칠함. 막힌 칸(벽) 있음. 되돌아가면 지워짐.
- **판 생성**: 무작위 **해밀턴 경로**를 먼저 만들고(뱀처럼 꺾이는 경로 + 무작위 뒤집기 변형), 경로에 안 쓰인 칸을 벽으로 → **항상 풀 수 있음**. 단계마다 크기·벽 비율 조정.
- **조작**: 터치/마우스 = 시작 칸에서 끌기. 키보드 = 방향키로 한 칸씩, Backspace 되돌리기.
- **점수**: 단계 클리어마다 칸 수 × 10, 힌트(첫 3칸 보여 주기) 사용 시 감점. 10분 제한 누적 점수형. maxScore 500,000.
- **HUD**: SCORE / STAGE / TIME
- **참고 코드**: `pipes.js`(판 생성·단계 진행·10분 제한), `maze.js`(격자 이동)
- **완료 조건**: 대각선 이동 불가 / 지나온 칸으로 되돌아오면 그 뒤가 지워짐 / 모든 칸 채우면 자동 클리어.

## 56. 네온 리듬 (`rhythm`)
- **종류/색**: 원탭 · `#ff5ec4` / `255,94,196` / `#2a0420`
- **핵심 재미**: 소리와 손가락이 맞아떨어지는 쾌감.
- **규칙**: 4개 레인으로 노트가 내려옴. 판정선에서 탭. Perfect(±50ms) / Good(±110ms) / Miss. 길게 누르기 노트 포함. 체력 바(미스 시 감소) 0이면 끝.
- **음악**: 파일 없이 **WebAudio로 즉석 생성**한 루프(드럼·베이스·멜로디, BPM 100~160). 노트 패턴은 생성한 음악의 박자에서 자동 추출 → 매 판 다른 곡. 곡 길이 90초, 끝까지 가면 클리어.
- **타이밍**: `AudioContext.currentTime` 기준(프레임 시간 X). 시작 전 "보정" 옵션(±ms 조절, `A.set('neowa_rhythm_offset')`).
- **조작**: 터치 = 레인 탭(멀티터치). 키보드 = D F J K.
- **점수**: Perfect 300, Good 100 × 콤보 배율(10콤보마다 +0.1, 최대 ×2). maxScore 2,000,000.
- **HUD**: SCORE / COMBO / ACC(정확도 %)
- **참고 코드**: `arcade.js`의 사운드 합성(`tone`), `sequence.js`(음높이)
- **완료 조건**: 탭 지연이 화면 프레임에 묶이지 않음 / 일시정지 후 재개 시 음악·노트 동기 유지 / 무음 모드에서도 플레이 가능(박자 표시 깜빡임).

## 57. 미로 탱크 (`tank`)
- **종류/색**: 액션 · `#ffd166` / `255,209,102` / `#2a1d00`

- **오프라인 진행**: 마지막 접속 시각 저장, 다시 오면 최대 8시간치 생산량 지급("자리 비운 동안 ○○ 생산!").
- **저장**: `A.set('neowa_idle_save', JSON)` 5초마다. 큰 수 표기(1.23K, 4.5M, 7.8B…).
- **Shell 사용법 주의**: 이 게임은 "끝"이 없음 → 점수 = 누적 생산량의 로그 기반 정수(예: `Math.floor(Math.log10(total) * 1000)`), 오른쪽 위에 "기록 저장" 버튼을 두고 누르면 `S.gameOver`(진행은 유지). 다시 하기 = 이어하기.
- **조작**: 탭. 키보드 = Space 탭, 1~8 구매.
- **maxScore**: 100,000
- **HUD**: SCORE / PER SEC / PRESTIGE
- **완료 조건**: 탭 연타 매크로 방지(초당 15회 이상 무시) / 저장 데이터 깨져도 새로 시작(오류 없이).

## 70. 오늘의 도전 (`daily`)
- **종류/색**: 두뇌 · `#ffd166` / `255,209,102` / `#2a1d00`
- **핵심 재미**: 매일 바뀌는 문제 — **매일 방문할 이유**.
- **규칙**: 날짜를 씨앗(seed)으로 한 결정적 난수로 **기존 퍼즐 3개를 하루 세트로 출제**(예: 스도쿠 쉬움 1판 + 불 끄기 3단계 + 다른 색 찾기 30초). 모두 같은 날 같은 문제. 하루 1회만 기록(재도전은 연습 모드).
- **구현**: `A.seedRand(dateString)` 같은 결정적 난수 함수를 이 게임 파일 안에 작성(mulberry32 등). 기존 게임 코드를 직접 불러오지 말고 **간단 버전을 이 파일 안에 다시 구현**(의존성 최소화).
- **연속 출석**: `neowa_daily_streak`, `neowa_daily_last`. 연속 일수 배지 표시.
- **메인 연동(선택)**: `index.html` 히어로 아래 "오늘의 도전" 버튼 — `build_hub.py`에 고정 링크 추가.
- **점수**: 세 문제 점수 합 × (1 + 연속 일수 × 0.05, 최대 ×2). maxScore 100,000.
- **HUD**: SCORE / STEP n/3 / STREAK
- **완료 조건**: 기기 시간대와 무관하게 한국 시간 기준 날짜 사용(`Date.now() + 9h`) / 이미 한 날은 결과 화면 바로 표시.
