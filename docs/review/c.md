# 게임 보완 기획서 — 묶음 C

대상: 네온 동굴(cave), 타이밍 링(ring), 바람 궁수(archery), 네온 하이웨이(lanes), 중력 반전(gravity), 우주 광부(rocks), 네온 슬래시(slash), 에어 하키(hockey), 골키퍼(keeper)

점검 방법: 게임마다 Playwright 스크립트로 문제 상황을 재현해, 고치기 전과 후를 비교했습니다. 게임 안의 변수를 직접 읽어 확인하고, 생성 규칙은 수천 번 돌려서 확인했습니다. smoke(휴대폰·PC·테슬라)는 9개 모두 통과했습니다.
표시: 🎨 = 그래픽 담당 스레드 몫, 🔊 = 사운드 담당 스레드 몫

---

## 1. 네온 동굴 (cave)
**현재 상태**: 누르기/떼기 비행. 처음 하는 사람은 0.6초 만에 떨어지고, 후반에는 따라갈 수 없는 지형이 나오던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 난이도 | 상 | 시작하자마자 추락해 0.6초 안에 죽음. 무엇을 할지 알 시간이 없음 |
| 난이도 | 상 | 후반 벽 꺾임이 초당 1100px 정도까지 나옴. 비행기 최고 상승 속도는 560px이라 따라갈 수 없음 |
| 버그 | 상 | 기둥이 동굴 높이와 거의 같게 생겨 통로가 10~30px만 남음 (지나갈 수 없음) |
| 재미 | 중 | 점수가 거리와 크리스털뿐이고 중간 목표가 없음 |
| 버그 | 하 | 창을 벗어나면 누름 상태가 남을 수 있음 |
| 성능 | 하 | 비행기를 그릴 때 매 프레임 shadowBlur 사용 🎨 |

**이번에 고친 것**
- 시작 대기: 처음 누를 때까지(최대 2.5초) 가운데에 떠 있고 "누르고 있으면 상승" 안내를 띄움
- 벽 기울기 제한: 지금 속도에서 초당 약 420px까지만 꺾임 (2만 조각 생성 점검: 최대 432px/s)
- 기둥: 한쪽에는 반드시 130px 이상 통로를 남기고, 기둥 사이는 속도에 맞춰 280px 이상 띄움 (676개 점검: 위반 0)
- 기둥 통과 +10, 가까이 스치면 "아슬아슬 +30", 500m마다 배너, 종료 화면에 아슬아슬 횟수
- 창을 벗어나면 누름 해제

**남은 제안**: 비행기 빛 번짐을 스프라이트로 바꾸기 🎨, 구간마다 동굴 색 바꾸기 🎨

## 2. 타이밍 링 (ring)
**현재 상태**: 바늘이 구간에 들어올 때 탭. 판정 구멍과 사람이 반응할 수 없는 후반 난이도 문제가 있던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 상 | 바늘이 한 프레임에 구간을 통째로 건너뛰면 실패로 안 잡힘. 그대로 한 바퀴 더 돎 |
| 난이도 | 상 | 20히트 뒤에는 구간을 지나는 시간이 0.04초. 실력이 아니라 운 |
| 재미 | 중 | 정중앙(퍼펙트)을 노릴 이유가 약함 |

**이번에 고친 것**
- 진행 방향 기준 거리로 판정해, 한 프레임에 구간을 건너뛰어도 실패로 잡힘 (재현해서 확인)
- 속도 상한을 6.5에서 5.4로 낮추고, 구간 통과 시간이 0.1초 밑으로 내려가지 않게 함 (0히트 0.34초 → 20히트부터 0.10초)
- 연속 퍼펙트 보너스: 2연속부터 +10씩, 최대 +50. HUD에 "PERFECT ×N" 표시, 종료 화면에 최다 연속 퍼펙트

**남은 제안**: 30히트 이후 구간이 천천히 움직이는 변형, 구간 두 개 동시 등장

## 3. 바람 궁수 (archery)
**현재 상태**: 당겨 쏘는 양궁 10발. 일시정지하면 게임이 멈춰 버리는 큰 버그가 있던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 상 | 쏜 뒤 0.7초 안에 일시정지(또는 창 전환)하면 다음 과녁으로 안 넘어가 **영원히 멈춤** (setTimeout이 일시정지 중에 실행되고 넘어감) |
| 버그 | 상 | 쏜 직후 다시 하기를 누르면 옛 타이머가 새 판을 건드림 |
| 버그 | 중 | 화살이 땅을 뚫고 화면 밖까지 날아감 |
| 안내 | 중 | 첫 화살을 어떻게 쏘는지 화면에 안내가 없음 |
| 재미 | 중 | 10발로 끝나서 잘 쏴도 더 할 수 없음 |
| 버그 | 하 | 창을 벗어나면 키 눌림이 남음 |

**이번에 고친 것**
- 다음 과녁 넘김을 게임 시간 타이머로 바꿈: 일시정지 → 계속하기, 다시 하기 모두 정상 (재현해서 확인)
- 화살이 땅에 꽂히면 빗나감으로 처리
- 정중앙(10점)이면 보너스 화살 +1. 난이도는 쏜 화살 수 기준이고 상한(12)이 있음. 종료 화면에 보너스 화살 수
- 첫 화살 전 안내 문구 (터치: "화면을 왼쪽 아래로 끌었다가 놓기" / PC: 마우스와 키보드 방법)
- 창을 벗어나면 키 눌림 해제

**남은 제안**: 과녁에 꽂힌 화살 남기기 🎨, 바람 깃발 애니메이션 🎨

## 4. 네온 하이웨이 (lanes)
**현재 상태**: 3차선 피하기. 피할 수 없는 차 벽이 생기고, 가만히 있어도 보너스를 받는 문제가 있던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 규칙 | 상 | 차마다 속도가 달라 뒤 줄이 앞 줄을 따라잡아 세 차선이 다 막힘 (피할 수 없는 죽음) |
| 규칙 | 상 | 두 차선을 막는 줄이 연달아 나오면 두 칸을 한 번에 옮겨야 할 때가 있음 |
| 규칙 | 중 | 코인이 차보다 빨리 내려와 다른 줄 차 쪽으로 플레이어를 끌어들임 |
| 재미 | 중 | 가운데 차선에 가만히 있으면 양옆 차마다 "아슬아슬 +30"을 받음 |
| 버그 | 중 | 최종 점수가 소수로 저장됨 |
| 안내 | 하 | 메인 카드 설명에 "연료"가 있는데 게임에는 연료가 없음 (catalog는 이 작업 범위 밖이라 보고만) |

**이번에 고친 것**
- 차 속도를 하나로 맞추고, 줄 간격을 거리(300~430px)로 관리해서 줄끼리 겹치지 않음
- 두 차선을 막는 줄의 빈 차선은 앞 줄의 빈 차선에서 한 칸 안에만 생김 (5000줄 점검: 위반 0). 단순한 봇이 최고 속도에서 4분 동안 살아남음
- 코인도 차와 같은 속도로 내려옴
- 아슬아슬: 그 차 차선에 있다가 0.6초 안에 옆으로 피했을 때만 인정. 4초 안에 이어 가면 배율이 올라감(최대 ×5), HUD에 표시
- 점수를 정수로 저장, 10km마다 배너

**남은 제안**: catalog 설명의 "연료" 문구 고치기(메인 담당), 차종 섞기(트럭은 2칸 길이) 🎨

## 5. 중력 반전 (gravity)
**현재 상태**: 탭으로 위아래 반전하며 달리기. 입력이 씹히는 느낌이 있고, 지나갈 수 없는 가시 배치가 나오던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 안내 | 상 | 착지 직전에 누른 탭은 그냥 무시됨 → "눌렀는데 안 된다"는 느낌 |
| 규칙 | 상 | 가시가 위아래로 너무 붙어 나와 지나갈 수 없는 배치가 생김 |
| 버그 | 중 | 바닥이나 천장을 달리는 중에는 위·아래 별에 닿아도 못 먹음 (거리 38 > 판정 34) |
| 재미 | 중 | 중간 목표와 아슬아슬 요소가 없음 |

**이번에 고친 것**
- 착지 0.15초 전 탭은 기억했다가 착지하자마자 반전, 발판 끝에서 떨어진 직후 0.08초 동안은 반전 허용
- 가시 간격 보장: 같은 쪽 60px, 반대쪽 150px 이상
- 별 판정 반경을 42로 늘림
- 가시 위를 공중에서 스치면 +15, 500m마다 배너, 종료 화면에 아슬아슬 횟수
- 점검: 앞을 내다보며 움직이는 봇이 최고 속도에서 10km(2분 반)를 달림

**남은 제안**: 끊긴 길과 가시가 이어질 때 꼭 지나갈 수 있는지 검사하는 생성기 (지금은 간격 규칙으로만 막음. 봇이 드물게 막힌 곳 1번 확인)

## 6. 우주 광부 (rocks)
**현재 상태**: 운석 부수기 슈팅. 손가락이 우주선을 가리고, 웨이브가 시작될 때 억울하게 죽을 수 있던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 안내 | 상 | 우주선이 손가락 위치로 날아가 손가락 밑에 숨음 (휴대폰에서 안 보임) |
| 난이도 | 상 | 새 웨이브 운석이 화면 가장자리에서 나오는데, 화면이 이어져 있어 우주선 바로 옆에서 생길 수 있음 → 즉사 |
| 난이도 | 중 | 웨이브 운석 수와 속도에 상한이 없고, 목숨을 되찾을 방법이 없음 |
| 버그 | 하 | 다른 손가락을 떼도 드래그가 끊김, 창 전환 뒤 키가 눌린 채로 남음 |

**이번에 고친 것**
- 가상 조이스틱: 누른 곳에서 끈 방향·거리만큼 추진하고, 링과 손잡이를 표시
- 운석은 우주선과 220px 이상 떨어진 곳에서만 생김 (화면 이음까지 계산, 200번 점검: 최소 220px)
- 웨이브 운석 최대 10개, 속도 상한 추가. 웨이브 3개를 넘길 때마다 목숨 +1(최대 5)
- 드래그는 누른 손가락으로만 끝남, 창을 벗어나면 키·드래그 해제

**남은 제안**: 연속 파괴 콤보 배율, 보스 운석(5웨이브마다)

## 7. 네온 슬래시 (slash)
**현재 상태**: 그어서 베기. 콤보가 끝없이 쌓이는 점수 구멍이 있고, 키보드로는 할 수 없던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 상 | 손가락을 떼지 않고 계속 그으면 한 판 내내 콤보가 이어짐 → 배율과 보너스가 끝없이 커짐 |
| 안내 | 상 | 키보드만으로는 할 수 없음 (사이트 규칙 위반) |
| 재미 | 중 | 놓친 수를 되찾을 방법이 없고, 특별한 도형이 없음 |

**이번에 고친 것**
- 콤보는 마지막으로 벤 뒤 0.45초 안에 이어 벤 것만 인정 (3개부터 보너스는 그대로)
- 키보드 칼날: 방향키/WASD로 빛나는 칼날을 움직이면 지나간 자리를 벰 (확인: 키보드로 3연속 베기와 콤보 보너스)
- 황금 도형(5%, 10초 이후): +50, 놓친 수 1 회복
- 칩·규칙·조작 안내를 실제 동작에 맞게 고침

**남은 제안**: 베기 효과음을 도형마다 다르게 🔊, 반쪽 조각의 단면 빛 🎨

## 8. 에어 하키 (hockey) — 혼자 / 둘이서
**현재 상태**: 컴퓨터 또는 친구(한 화면)와 하는 7점 승부. 빠르게 휘두르면 퍽이 말렛을 뚫고 지나가던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 상 | 말렛을 빠르게 휘두르면 한 프레임에 86px씩 움직여 퍽 뒤로 빠짐 → 퍽이 내 골문 쪽으로 감 (재현: 63번 중 42번) |
| 버그 | 중 | 터치로 누르는 순간 말렛이 50px 튐 (누를 때와 움직일 때 간격이 다름). 둘이서 모드의 P2도 같음 |
| 버그 | 하 | 창을 벗어나면 키가 눌린 채로 남음 |

**이번에 고친 것**
- 말렛도 퍽과 함께 잘게 나눠 움직임 (나누는 횟수는 이동 거리에 맞춤) → 63번 중 0번
- 누르는 순간부터 같은 간격(50px) 적용 (P1은 손가락 위, P2는 손가락 아래)
- 창을 벗어나면 키 해제
- 둘이서 모드 확인: 키보드 P1(방향키)/P2(WASD) 따로 움직임, 두 손가락 동시 터치 각각 추적, 7점 승리 화면 "P1 승리!", 최고기록에 안 남음

**남은 제안**: 라운드별 컴퓨터 성격 차이(공격형·수비형), 퍽 속도에 따른 꼬리 효과 🎨

## 9. 골키퍼 (keeper)
**현재 상태**: 날아오는 슛 막기. 페인트 슛은 키보드로 거의 못 막고, 한번 실점하면 되찾을 방법이 없던 게임.

| 분류 | 우선 | 내용 |
|---|---|---|
| 난이도 | 상 | 페인트 슛이 날아가는 시간의 50% 지점에서 꺾여 후반에는 반응할 시간이 0.3초. 키보드(초당 700px)로는 거의 못 막음 |
| 재미 | 중 | 실점은 쌓이기만 하고, 정확히 막아도 보상이 같음 |
| 안내 | 중 | 첫 슛 전에 무엇을 할지 안내가 없음 |
| 버그 | 하 | 터치 취소(pointercancel)를 처리하지 않음, 창 전환 뒤 키가 남음 |

**이번에 고친 것**
- 페인트 슛은 35% 지점부터 꺾이고(그림자도 같이), 키보드 이동은 초당 900px
- 10연속 선방마다 실점 1 회복, 장갑 정중앙으로 막으면 "완벽 선방 +10", 10선방마다 배너
- 첫 슛 전 "장갑을 끌어 그림자 위로!" 안내
- 터치 취소와 창 전환 처리

**남은 제안**: 슈터 캐릭터와 킥 동작 🎨, 관중 함성 🔊

---

## 공통
- 점수는 모두 정수입니다. 점수 체계가 조금 바뀌었지만(보너스 추가) catalog의 maxScore를 넘을 가능성은 낮습니다. 확인한 값: ring 20,000 / archery 5,000 / keeper 10,000 / lanes 300,000 (봇이 4분에 약 6.8만점)
- 저장 키, 엔진 예약 키, 공통 엔진, 사운드 체계는 건드리지 않았습니다. 이미 있는 `A.sfx` 이름과 `fx` 효과만 썼습니다.
