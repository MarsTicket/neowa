# 게임 보완 기획서 — 묶음 d

대상: 두더지 탭(whack), 탑뷰 레이서(racer), 큰 물고기(fishy), 도시 방어(defense), 네온 서바이버(survivor), 네온 미로(maze), 구름 점프(jumper), 포격전(artillery), 네온 핀볼(pinball)

점검 방법: 게임마다 Playwright로 페이지를 열고, 게임 안 변수를 읽는 자동 플레이(봇)를 1~2분 돌려 막힘·누수·난이도를 쟀습니다. 미로는 300판씩 모의 생성해 풀 수 있는지 셌습니다. 마지막에 `smoke.js`(휴대폰·PC·테슬라 30개 항목) 모두 통과.

공통으로 남긴 것(그래픽 담당 스레드 몫): racer·fishy·maze·survivor·pinball은 `render`에서 매 프레임 `shadowBlur`를 씁니다(지침 8장 위반, 테슬라에서 느릴 수 있음). 그래픽을 새로 그리는 스레드가 `A.sprite()`로 바꾸는 것이 맞아 이번엔 손대지 않았습니다.

## 1. 두더지 탭 (whack)
**현재 상태:** 60초 두더지 잡기. 규칙은 단순하고 잘 돌아가지만 막판 긴장감이 없고, 잡은 두더지를 한 번 더 누르면 콤보가 끊겼음.

| 분류 | 우선순위 | 내용 |
|---|---|---|
| 버그 | 상 | 이미 잡은(쓰러지는 중인) 두더지를 연타하면 '헛방'으로 처리돼 콤보가 0 |
| 재미 | 중 | 마지막 몇 초에 특별한 일이 없음. 남은 시간 경고도 없음 |
| 재미 | 중 | 황금 두더지가 점수 3배뿐이라 노릴 이유가 약함 |
| 난이도 | 하 | 난이도를 '남은 시간'으로 계산 → 시간이 늘어나는 장치를 넣으면 쉬워지는 구조 |

**이번에 고친 것**
- 잡은 두더지를 다시 눌러도 콤보 유지. 빈 구멍을 누르면 '헛방!' 글자로 이유를 보여 줌
- 마지막 10초 **FEVER**(점수 2배, 배너, 화면 테두리 깜빡임), 남은 5초 째깍 소리, 10초 이하 시간 빨간색
- 황금 두더지 +2초, 10콤보마다 큰 글자 알림
- 난이도 기준을 '지난 시간'으로 바꿈
- 안내문(rules, desc)에 FEVER·황금 +2초·헛치면 콤보 끊김 반영

**남은 제안**
- 두더지·폭탄 그림, 망치 타격 연출 → 그래픽 스레드 몫
- 연속 헛방 시 잠깐 손 저림(입력 막힘) 같은 벌칙은 어린이 사용자에게 답답할 수 있어 보류

## 2. 탑뷰 레이서 (racer)
**현재 상태:** 구불한 도로 + 연료. 고속에서 물체 간격이 불공정하게 좁아지고, 후반엔 연료통이 넘쳐 끝이 안 나는 구조였음.

| 분류 | 우선순위 | 내용 |
|---|---|---|
| 난이도 | 상 | 물체 간격이 거리(px) 기준으로 줄어 최고속(1050px/s)에선 0.07초 간격 → 피할 수 없는 장애물 |
| 난이도 | 중 | 고속일수록 연료통도 자주 와서 연료가 오히려 넉넉해짐 |
| 재미 | 중 | 장애물을 아슬아슬 피해도 보상이 없음. 거리 목표 없음 |
| 안내 | 하 | 연료가 바닥나기 전 경고 없음 (숫자 색만 바뀜) |
| 버그 | 하 | 시작 위치가 차가 그려지는 도로 지점과 달라 첫 순간 도로 가장자리에서 출발. 최종 점수 소수 |

**이번에 고친 것**
- 물체 간격을 **시간 기준**(현재 속도 × 0.45~0.8초, 후반 최대 30% 짧아짐)으로
- 후반으로 갈수록 연료통 비율↓ 장애물 비율↑, 연료 소모 조금↑ → 봇 기준 약 2분·110km에서 끝남
- **아슬아슬 보너스**(장애물 옆 80px 이내 통과, 연속일수록 +30~+80), **10km마다 배너 보너스**
- 연료 25 미만에서 '연료 부족!' 경고음·글자
- 시작 위치 보정, 점수 정수 처리, 안내문에 연료/부스터/아슬아슬 추가

**남은 제안**
- 차 그림자·도로 질감, 부스터 화면 효과 → 그래픽 스레드 몫 (차의 매 프레임 shadowBlur 포함)
- 다른 차(움직이는 장애물) 추가는 다음 기회에

## 3. 큰 물고기 (fishy)
**현재 상태:** 작은 물고기를 먹고 크는 게임. 큰 물고기가 화면 끝에서 갑자기 튀어나와 억울한 죽음이 많고, 성장이 너무 느렸음.

| 분류 | 우선순위 | 내용 |
|---|---|---|
| 난이도 | 상 | 큰 물고기가 화면 밖 60px에서 출발 → 몸이 커서 등장과 동시에 가장자리의 나를 덮침 |
| 버그 | 상 | 화면 밖 120px를 넘으면 지우는 규칙 때문에 아주 큰 물고기는 생기자마자 지워지거나 반쯤 보이다 사라짐 |
| 난이도 | 상 | 위험한 물고기가 절반 이상. 크기 1→2에 10~20마리 필요해 초반이 지루하고 어려움 |
| 안내 | 중 | 안내는 '크기 10단계'인데 실제론 14단계 |
| 난이도 | 중 | 시작 직후 무방비 |
| 재미 | 중 | 연속으로 먹는 손맛·특별한 먹이가 없음 |

**이번에 고친 것**
- 물고기를 몸 크기만큼 화면 밖에서 출발시키고, 화면을 떠날 때만 지움
- 위험한 물고기가 다가오면 **화면 끝에 빨간 ▶ 경고**
- 시작 2초 무적(깜빡임), 처음 8마리 중 5마리는 확정 먹이, 내 주변 230px 비움
- 먹이 비율 약 65%, 성장 필요량 `5 + 크기×3`, 먹이 1마리 최소 1경험치 → 봇 기준 90초에 크기 7
- 최대 크기 10(안내와 일치), 이후 먹을 때마다 '바다의 왕 +500'
- **연속 먹기 배율**(1.6초 안, 최대 ×5, HUD 표시), 5% 확률 **빠른 황금 물고기**(5배)

**남은 제안**
- 물고기 모양 다양화, 성장 시 확대 연출 → 그래픽 스레드 몫 (내 물고기의 매 프레임 shadowBlur 포함)
- 거품이 프레임 수 기준으로 움직임(장식이라 영향 적음) → 그래픽 스레드가 다시 그릴 때 함께

## 4. 도시 방어 (defense)
**현재 상태:** 미사일 요격. 연쇄 점수가 '폭발이 하나라도 남아 있는 동안' 계속 쌓여, 쉬지 않고 쏘면 10연쇄·20연쇄로 점수가 부풀었음.

| 분류 | 우선순위 | 내용 |
|---|---|---|
| 버그 | 상 | 연쇄 카운터가 전체 공유 → 아무 데나 계속 쏘면 연쇄 배율이 끝없이 오름 (점수 폭주) |
| 안내 | 중 | 요격탄이 0일 때 눌러도 아무 반응 없음 (고장처럼 보임) |
| 재미 | 중 | 미사일이 한 종류뿐, 1웨이브가 느림 |
| 재미 | 하 | 도시를 지켜 낸 보상이 약함. 도시 복구가 조용히 일어남 |
| 난이도 | 하 | 미사일 속도 상한 없음 |

**이번에 고친 것**
- 연쇄를 **요격탄 한 발에서 이어진 폭발끼리만** 세도록 (폭발마다 공유 카운터)
- '요격탄 없음' 알림 + 소리
- 4웨이브부터 **빠른 노란 미사일**(1.6배 속도, 점수 2배, 분열 안 함), 기본 속도 소폭↑, 상한 240
- 도시를 하나도 안 잃은 웨이브 **완벽 방어 보너스**(300×웨이브), 복구 알림(남은 도시 2곳 이하면 최소 1곳 복구)
- 종료 화면에 최대 연쇄, 안내문 갱신

**남은 제안**
- 폭발·도시 파괴 연출 강화 → 그래픽 스레드 몫
- 폭격기(가로로 지나가며 미사일 투하) 같은 새 적은 다음 기회에

## 5. 네온 서바이버 (survivor)
**현재 상태:** 자동 사격 생존 게임. 레벨업이 겹치면 선택이 사라지고, 오래 하면 배열이 계속 커지는 문제가 있었음.

| 분류 | 우선순위 | 내용 |
|---|---|---|
| 버그 | 상 | 같은 프레임에 보석을 여러 개 먹어 레벨업이 두 번 나면, 레벨만 오르고 선택 1번이 사라짐 |
| 버그 | 상 | 멀리 두고 온 보석이 영원히 남음, 적 수 상한 없음 → 오래 하면 느려짐 |
| 버그 | 중 | 능력 상한 없음: 연사 속도가 0에 가까워지고 체력 칸이 화면 밖으로 넘침 |
| 재미 | 중 | 보스가 5분에 한 번뿐이라 대부분 못 봄. 보스 위치·체력을 알 수 없음 |
| 재미 | 하 | 체력 회복 수단이 레벨업 '회복' 하나뿐 |
| 버그 | 하 | 죽는 폭발이 내 위치가 아니라 화면 가운데 |

**이번에 고친 것**
- 레벨업 대기: 선택 중엔 다음 레벨업을 미루고, 고른 뒤 남은 경험치로 이어서 다시 고르게
- 보석·♥는 1100px 이상 멀어지면 정리, 적 최대 150마리
- 능력 상한(연사 0.1초, 다중 발사 7, 구슬 6, 관통 5, 자석 400, 이동 420, 체력 10) 도달 시 후보에서 제외
- 보스를 **2분 30초마다**(매번 60%씩 단단해짐), **보스 체력 바 + 화면 밖 위치 점**
- 1.2% 확률(보스는 확정)로 ♥ 드롭(체력 +1)
- 안내문 갱신(♥, 보스 주기)

**남은 제안**
- 적·총알·구슬 그래픽, 피격 연출 → 그래픽 스레드 몫 (내 캐릭터 매 프레임 shadowBlur 포함)
- 새 무기 종류(레이저, 범위 공격)는 밸런스 작업이 커서 보류

## 6. 네온 미로 (maze)
**현재 상태:** 스와이프로 미끄러지는 미로. **대부분의 판이 풀 수 없었음** — 가장 큰 문제.

| 분류 | 우선순위 | 내용 |
|---|---|---|
| 규칙 | 상 | '벽까지 미끄러짐' 규칙에선 갈림길에 멈출 수 없음. 300판 모의 실험 결과 7x7은 53%, 11x11은 84%, 17x17은 98%가 출구에 못 가거나 빠져나올 수 없는 곳에 갇히는 판 |
| 조작 | 중 | 움직이는 중 입력은 버려짐. 스와이프마다 손을 떼야 함 |
| 난이도 | 중 | 잘하면 남은 시간이 끝없이 쌓임 (봇 6단계에 189초) |
| 재미 | 하 | 잘 풀었는지 알 수 있는 기준이 없음 |
| 버그 | 하 | 별이 출구나 같은 칸에 겹쳐 생김 |

**이번에 고친 것**
- **갈림길(옆으로 길이 열린 칸)에서도 멈추게** → 모든 판 100% 풀림, 갇힘 0 (300판×6크기 모의 실험)
- 출구까지 **최소 횟수(BFS)** 계산, HUD에 `횟수 / 최단 N수`, 최단으로 탈출하면 보너스
- 움직이는 중 입력 1개 저장 후 실행, 손을 떼지 않고 연속 스와이프, 키 꾹 누름 반복 무시
- 남은 시간 상한 90초, 단계당 추가 시간 `10 + 크기×1.1`
- 별 겹침 방지, 안내문·설명을 새 규칙에 맞춤

**남은 제안**
- 힌트(다음 한 수 깜빡임) 버튼: 최단 경로 계산은 이미 있어 쉽게 붙일 수 있음. 화면 버튼 배치가 사이트 UI 스레드와 겹칠 수 있어 보류
- 공·벽 그래픽 → 그래픽 스레드 몫 (공의 매 프레임 shadowBlur 포함)

## 7. 구름 점프 (jumper)
**현재 상태:** 자동 점프 위로 오르기. 부서지는 발판 때문에 못 올라가는 구간이 생기고, 높이 가면 스프링이 사라졌음.

| 분류 | 우선순위 | 내용 |
|---|---|---|
| 규칙 | 상 | 부서지는 발판이 '밟을 발판' 자리를 차지 → 밟을 수 있는 발판 간격이 최대 360px (점프 높이 256px) = 피할 수 없는 죽음 |
| 버그 | 중 | 확률 순서 오류로 높이 약 900m 이후 스프링·로켓이 0% |
| 난이도 | 하 | 후반에도 발판 폭이 같음 |
| 재미 | 하 | 높이 목표·중간 보상 없음 |

**이번에 고친 것**
- 부서지는 발판은 **덤으로만** 추가 → 밟을 수 있는 발판 간격 항상 180px 이하 (봇·고고도 강제 실험으로 최대 172px 확인)
- 스프링 6%, 로켓 1.5%를 먼저 뽑도록 순서 수정
- 발판 폭 92 → 72(높이 비례), **250m마다 배너 보너스**
- 안내문에 스프링·로켓 표시 추가

**남은 제안**
- 적(구름 괴물)·총알 같은 방해 요소는 조작이 늘어나 보류
- 배경 하늘 변화, 캐릭터 표정 → 그래픽 스레드 몫

## 8. 포격전 (artillery)
**현재 상태:** 턴제 포격. 차례 넘김이 `setTimeout`이라 일시정지·다시 하기에 약했고, 후반 적이 거의 백발백중이었음.

| 분류 | 우선순위 | 내용 |
|---|---|---|
| 버그 | 상 | 적 차례 대기 중 일시정지하면 예약된 동작이 '플레이 중 아님'으로 취소 → 다시 시작해도 영원히 멈춤 |
| 버그 | 상 | 판이 끝난 직후 '다시 하기'를 누르면 이전 판의 예약 동작이 새 판에 끼어듦 |
| 난이도 | 상 | 체력 3이 판 전체에서 회복 없음 + 7전투부터 적 오차 0.03(거의 백발백중) → 운에 좌우되는 끝 |
| 버그 | 중 | 구덩이가 계속 깊어져 포대가 화면 아래로 사라질 수 있음 |
| 안내 | 중 | 첫 화면에 '당겨서 쏘기' 방향을 알려 주지 않음 |
| 재미 | 하 | 정확히 맞혀도 보상 차이 없음 |

**이번에 고친 것**
- 차례 넘김을 `update` 안 타이머(`later()`)로: 일시정지 중엔 멈추고, 다시 하기 때 지워짐 (실험: 대기 중 2.5초 일시정지 후 정상 진행)
- 전투 승리 시 **체력 +1**(최대 3), 적 오차 하한 0.09·감소 폭 완화
- 땅 깊이를 화면 아래 60px까지로 제한
- **직격**(22px 이내) 점수 2배, 첫 차례에 조작 안내 문구(터치/키보드 따로)
- 안내문 갱신

**남은 제안**
- 미리보기 궤적에 바람을 반영할지(쉬워짐) 여부는 사이트 주인 판단이 필요해 그대로 둠
- 무기 선택(3발 산탄, 굴착탄)은 다음 기회에
- 포탄·폭발 그래픽 → 그래픽 스레드 몫

## 9. 네온 핀볼 (pinball)
**현재 상태:** 좌우 플리퍼 핀볼. 플리퍼가 빨리 돌면 공을 통과시키는 판정 문제가 있었음.

- 안내문 갱신

**남은 제안**

## 가로 화면 (2단계)

**문제:** 휴대폰 가로·테슬라·PC 가로에서 540x960 세로형 판이 화면 높이에 맞춰 줄어 아주 작아졌습니다(휴대폰 가로에서 폭 206px).
**방법:** 오목(`gomoku.js`)과 같은 방식으로 게임마다 `land: [가로, 세로]` 크기를 따로 정하고, `onResize`에서 판 배치를 다시 계산합니다. 가로에선 점수판을 오른쪽 패널(`gp-stats`)로 옮기고 판 위 점수판은 숨깁니다(`data-land-hide`). 공통 엔진은 건드리지 않았습니다.

### 판 크기 전후 (화면에 그려지는 캔버스 px)

| 게임 | 가로 판 | 휴대폰 가로 844x390 | 테슬라 1180x720 | PC 1440x900 | 휴대폰 세로 390x844 |
|---|---|---|---|---|---|
| whack | 720x720 정사각형 | 206x366 → **366x366** | 391x696 → **696x696** | 493x876 → **876x876** | 366x650 (그대로) |
| maze | 720x720 정사각형 | 미로 약 190px → **349px** | 약 360px → **663px** | 약 453px → **835px** | 그대로 |
| artillery | 900x600 가로 전장 | 206x366 → **522x348** | 391x696 → **750x500** | 493x876 → **968x645** | 그대로 |
| defense | 900x600 가로 전장 | 206x366 → **522x348** | 391x696 → **750x500** | 493x876 → **968x645** | 그대로 |
| fishy | 960x600 넓은 바다 | 206x366 → **522x326** | 391x696 → **750x468** | 493x876 → **968x605** | 그대로 |
| survivor | 900x600 넓은 시야 | 206x366 → **522x348** | 391x696 → **750x500** | 493x876 → **968x645** | 그대로 |

### 게임별 내용
- **whack:** 3x3 구멍을 정사각형 판에 넓게 배치. 구멍이 약 1.3배 크게 보임. 화면을 돌려도 나와 있는 두더지·시간 유지(구멍 위치만 다시 계산). 휴대폰 가로에서 터치로 두더지를 잡는 것까지 확인.
- **maze:** 칸 크기·판 위치만 다시 계산하고 미로 내용·공 위치·시간은 그대로. '횟수 / 최단' 표시는 패널 카드로.
- **artillery:** 두 포대가 양 끝에서 마주 보는 가로 전장. 지형을 화면 비율 기준으로 만들어 세로는 예전과 같고, 가로는 언덕을 조금 높게. 전투 중 화면을 돌리면 지형·포대·날아가는 포탄을 새 크기에 맞춰 늘이고 줄임. 가로 글자는 1.45배. 가로에서 자동 플레이로 3전투 이상 진행 확인.
- **defense:** 도시 6곳을 넓게 펼친 가로 전장. 낙하 거리가 짧아진 만큼 미사일 속도 ×0.7. 화면을 돌리면 도시·미사일·요격탄·폭발·조준점을 옮김.
- **fishy:** 물고기가 옆으로 헤엄치는 게임이라 가로가 자연스러움. 화면을 돌리면 모든 물고기·거품 위치를 비율대로 옮김. 가로에서 자동 플레이로 크기 6까지 성장 확인.
- **survivor:** 카메라가 따라가는 열린 맵이라 가로 시야가 더 넓고 유리. 레벨업 카드 위치를 가로용으로 바꾸고 터치 판정도 같은 위치 함수 사용(가로 터치로 3번째 카드 선택 확인). 화면을 돌리면 카메라만 보정해 캐릭터가 가운데에 남음.

### 세로 유지
- **racer:** 도로가 위에서 아래로 흘러 앞을 멀리 보는 게임이라 세로가 필요.
- **jumper:** 위로 계속 올라가는 게임이라 세로가 필요.
- **pinball:** 공이 아래로 떨어지는 세로 테이블 구조라 세로가 필요.

### 점검
- `smoke.js` 9개 게임 × 휴대폰·PC·테슬라 모두 통과.
- 바꾼 6개 게임 모두 Playwright로 844x390(터치)·1180x720(터치)·1440x900·390x844 네 화면에서 시작해 판 크기를 재고 스크린샷을 직접 확인함.
- 회전 확인: 390x844 → 844x390 → 390x844로 바꾸며 게임 상태(판 내용, 위치, 시간, 차례, 체력)가 유지되는지 확인. 오류 0.

## 3단계: 재미·재방문

**공통**
- **첫 판 안내:** 판 위에 한 줄짜리 말풍선과 필요한 곳엔 통통 튀는 화살표를 띄웁니다. 터치 기기와 키보드 기기 문구가 다릅니다. 첫 올바른 행동을 하면 사라지고 `neowa_<id>_tut = 1`로 저장해 다음부터 안 나옵니다. localStorage를 비운 상태(보임)와 키가 있는 상태(안 보임)를 9개 게임 모두 Playwright로 확인했습니다.
- **종료 화면 '최고 대비':** 개인 최고 기록과의 차이(`+N 신기록` / `-N` / 첫 기록)를 meta에 보여 줍니다.

| 게임 | 첫 판 안내 (사라지는 조건) | 판 안의 목표·후반 변화 | 종료 화면 meta |
|---|---|---|---|
| whack | 두더지를 가리키는 화살표 (첫 두더지 잡기) | (1단계 FEVER 있음) | 잡은 수 · 최대 콤보 · 최고 대비 |
| racer | 좌우 운전·연료통 (0.7초 조향) | **32km부터 마주 오는 빨간 차** + 배너 | 거리 · 아슬아슬 횟수 · 최고 대비 |
| fishy | 헤엄·초록만 먹기 (첫 먹기) | **'다음 크기까지' 진행 막대** (예전엔 성장 진행이 안 보였음) | 최대 크기(먹은 수) · 최대 연속 · 최고 대비 |
| defense | 미사일 앞을 가리키는 화살표 (첫 요격) | **'남은 적 N'** 표시로 웨이브 끝이 보임 | 웨이브 · 최대 연쇄 · 최고 대비 |
| survivor | 끌어서 이동·자동 공격 (1초 이동) | **보스 1분 전부터 '보스까지 N초'** | 버틴 시간 · 처치·레벨 · 최고 대비 |
| maze | 스와이프 방법 (첫 이동) | **오늘의 미로**(아래), **6초 멈추면 힌트 화살표** | 단계 · 최고 대비 / 오늘의 미로는 남은 시간·오늘 최고 |
| jumper | 좌우로 끌어 착지 (0.5초 조작) | (1단계 250m 보너스·발판 폭 감소 있음) | 높이 · 코인 · 최고 대비 |
| artillery | 기존 안내를 '첫 발 쏘기 전까지만'으로 | **바람 표시 강화**(아래) | 전투 · 명중률 · 최고 대비 |
| pinball | 플리퍼 누르는 법 + 화살표 (첫 플리퍼) | (1단계 보너스 공 있음) | 최고 배율 · 타깃 완성 · 최고 대비 |

**미로 '오늘의 미로'**
- 시작 화면에 모드 버튼 `무한 모드 / 오늘의 미로`. 선택은 새 키 `neowa_maze_diff`(0 = 예전 모드)에 저장합니다.
- 오늘의 미로는 로컬 날짜(YYYYMMDD)로 시드를 고정한 같은 5단계입니다(mulberry32). 다 풀면 CLEAR 화면이 나오고, 하루 최고는 `neowa_maze_daily_YYYYMMDD`에 저장합니다.
- 같은 날 두 번 열었을 때 같은 판, 무한 모드는 매번 다른 판인 것을 확인했습니다.
- 힌트: 6초 동안 안 움직이면 다음 한 수를 초록 화살표로 알려 줍니다. 힌트를 본 단계는 최단 보너스가 없습니다.

**포격전 바람 표시 (결정 반영)**
- 궤적 미리보기에는 바람을 넣지 않았습니다.
- 바람 글자를 키웠습니다(세로 20px, 가로 28px). 세기별 색(약 하늘·중 노랑·강 주황)과 '약/중/강' 글자, 화살표 머리를 붙였고, 바람이 0이면 '바람 없음'으로 보입니다.
- 세로·휴대폰 가로·테슬라 스크린샷으로 잘 보이는지 확인했습니다.

**그 밖에 고친 것**
- 핀볼: 아주 짧게 톡 친 터치는 플리퍼가 안 움직였습니다. 이제 최소 0.1초는 올라갑니다.

**사이트 공통 제안 (엔진 몫이라 이번엔 안 함)**
- 업적 배지: "두더지 50콤보", "미로 최단 10번" 같은 게임별 업적을 공통 엔진이 모아 메인에 진열
- 일일 도전 허브: 각 게임의 '오늘의 판'(미로처럼 날짜 시드)을 메인에서 한 줄로 보여 주고, 연속 참여 일수 표시
- 종료 화면 공통 '최고 대비' 줄: 지금은 게임마다 meta로 넣었지만, 엔진이 점수 아래에 자동으로 보여 주면 meta 칸을 하이라이트에 쓸 수 있음
- 첫 판 안내 공통 함수: 지금 게임 코드에 들어간 `tutDraw`를 엔진의 `A.tut()`로 옮기면 다른 게임도 쉽게 붙일 수 있음
