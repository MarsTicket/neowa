# 신규 게임 점검·보완: PR #16 (다리 잇기 · 나이트 투어 · 사목 · 숫자 합치기 · 한붓 그리기)

브랜치 `improve/newgames-16` (원 브랜치 `claude/new-games-bridge-knight-four` 위). 기준: 1단계(버그·막힘·조작·난이도) → 가로 화면 → 첫 플레이 안내.

## 다리 잇기 `bridge`
- 현재 상태: 규칙·연출 모두 좋음. 세로형 판만 있어 가로 화면에서 아주 작았음.

| 분류 | 우선 | 내용 |
|---|---|---|
| 안내 | 중 | 휴대폰·테슬라 가로에서 판 폭 206px/391px로 너무 작음 |
| 난이도 | 중 | 다음 기둥 거리가 화면 폭(W)에 묶여 있어 판 크기를 바꾸면 난이도가 달라질 구조 |
| 안내 | 하 | 첫 안내 문구가 터치/키보드 구분 없음, 매 판 같은 문구 |

- 고친 것
  - 가로 화면 720×720 판 + 패널 점수판(SCORE·PERFECT·BEST). 화면 회전 때 카메라·주인공 위치를 옮겨 진행 상태 유지.
  - 다음 기둥까지 최대 거리를 고정 값 384로 계산 → 세로·가로 난이도 동일(원래 세로 값과 같음).
  - 첫 판에만(`neowa_bridge_tut`) 큰 안내 상자 + 다음 기둥 화살표. 누르는 중엔 "닿을 만큼 자라면 떼세요". 첫 기둥을 건너면 저장.
- 남은 제안: 후반(50점+) 움직이는 기둥 같은 새 변화. 배경 그래픽은 그래픽 스레드 몫.

## 나이트 투어 `knight`
- 현재 상태: 출발 가능 칸 계산·힌트·되돌리기·가로 판까지 잘 되어 있음. 다만 실수가 아주 늦게 드러나는 퍼즐이라 되돌리기 3번으로는 막히기 쉬움.

| 분류 | 우선 | 내용 |
|---|---|---|
| 막힘 | 상 | 이미 완주 불가인 상태에서 힌트를 누르면 "되돌려 보세요"만 나오고 몇 칸을 되돌려야 할지 알 수 없음 |
| 막힘 | 상 | 막혔을 때 되돌리기가 0이면 힌트가 남아도 바로 끝남 |
| 안내 | 중 | 파란 칸(갈 수 있는 곳)의 의미를 처음엔 모름 |

- 고친 것
  - 힌트: 완주가 안 되는 상태면 완주 가능한 지점까지 자동으로 되돌린 뒤 다음 칸을 표시(되돌리기 횟수는 안 씀, "N칸 되돌렸어요" 표시).
  - 막힘 상태에서도 힌트 사용 가능. 세로 화면은 되돌리기·힌트·끝내기 3버튼, 가로 패널은 끝내기 버튼 추가. 둘 다 0일 때만 자동 종료.
  - 첫 판 안내(`neowa_knight_tut`): 출발 칸 고르기 → "파란 칸 = L자로 갈 수 있는 곳". 두 번 움직이면 사라짐.
- 남은 제안: 8×8 반복 구간에 막힌 칸(벽) 섞기.

## 사목 `four`
- 현재 상태: 큰 문제 없음. 어려움(7수 읽기)도 PC에서 긴 멈춤(50ms 이상) 없음 확인. 가로 정사각형 판 이미 있음.
- 고친 것: 없음(점검만).
- 남은 제안: 가로 패널에 난이도 표시, 종료 화면에 개인 최고 대비.

## 숫자 합치기 `merge`
- 현재 상태: 쏘기·연쇄·512 보너스 정리·막힘 판정 정상. 첫 안내 있음.
- 가로 화면: **세로 유지**. 7칸 높이 열에 위에서부터 쌓고 아래에서 쏘는 구조라 정사각형으로 바꿔도 판이 1.3배 정도밖에 안 커짐.
- 남은 제안: NEXT와 지금 블록 바꾸기(보관) 기능.

## 한붓 그리기 `paint`
- 현재 상태: 항상 풀리는 판, 가로 판 있음.

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 상 | 힌트가 정답 하나와만 비교해서, 내가 칠한 길이 다른 방법으로 풀리는 길이어도 지워 버림 |
| 재미 | 하 | 10분 한 판은 지침(1~5분)보다 김. 메인 카드 태그가 "10분 도전"이라 이번엔 유지 |

- 고친 것: 힌트가 먼저 지금 칠한 길을 그대로 이어 완성할 수 있는 길을 찾고, 있으면 지우지 않고 다음 3칸을 칠함. 없을 때만 정답과 갈린 곳까지 되돌림.
- 남은 제안: 5분 모드(메인 카드 문구도 함께 바꿔야 해서 보류).
