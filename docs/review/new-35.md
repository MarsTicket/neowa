# 신규 게임 점검·보완: PR #35 (색 병 정렬 · 합 퍼즐 · 육각 블록)

브랜치 `improve/newgames-35` (원 브랜치 `claude/new-games-sort-sum-hexa` 위, #16 위에 쌓인 브랜치라 #35의 3종만 고침).

## 색 병 정렬 `sort`
- 현재 상태: 풀리는 판만 내고(12색까지 16ms 이내), 붓기 연출·되돌리기 좋음. 가로 화면에서 판이 작음.

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 상 | 빈 병 추가 후 되돌리기를 누르면 추가한 병까지 사라지고, 단계마다 1번이라 다시 추가도 못 함(병 위에 내용물이 있었다면 색이 통째로 없어짐) |
| 안내 | 중 | 가로 화면에서 판 폭 206px |
| 재미 | 하 | 10분 한 판은 지침(1~5분)보다 김. 메인 카드 태그 "10분 도전"이라 유지 |

- 고친 것: 빈 병을 추가하면 되돌리기 기록에도 빈 병을 넣어 되돌려도 병이 남음. 가로 화면 720×720 판 + 패널(점수판·되돌리기·빈 병 추가 큰 버튼).
- 남은 제안: 힌트(다음 한 수) 버튼, 5분 모드.

## 합 퍼즐 `sum`
- 현재 상태: 답이 하나뿐인 판 생성, 조합 안내·메모·힌트 다 있음.

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 상 | 어려움(9×9) 판 만들기가 1~3초 걸려(PC 기준, 테슬라는 더 김) 시작 버튼을 누르면 화면이 멈춤 |
| 안내 | 중 | 가로 화면에서 9×9 판 한 칸이 약 21px — 누르기 힘듦 |

- 고친 것
  - 시작 화면·결과 화면에 있는 동안 다음 퍼즐을 한 번에 한 판씩(16ms 간격) 미리 만들어 둠. 미리 만든 게 없을 때만 예전처럼 바로 만듦. 확인: 어려움 시작 때 50ms 넘는 멈춤 0건.
  - 가로 화면 960×720: 왼쪽 680 판 + 오른쪽 숫자 3×3·지우기·메모·힌트, 위쪽에 고른 줄의 조합 안내. 패널 점수판.
- 남은 제안: "오늘의 퍼즐"(날짜 시드). 이번엔 보류.

## 육각 블록 `hexa`
- 현재 상태: 세 방향 줄 지우기, 미리보기, 콤보 정상.

| 분류 | 우선 | 내용 |
|---|---|---|
| 조작 | 상 | 키보드 ↑↓가 한쪽 대각선으로만 움직여 위아래로 똑바로 못 감 |
| 안내 | 중 | 가로 화면 판 폭 206px |

- 고친 것: ↑↓는 처음 x 위치를 기억해 왼쪽 위/오른쪽 위를 번갈아 골라 거의 똑바로 이동. 가로 화면 720×720 판 + 패널 점수판.
- 남은 제안: 조각 하나 보관(홀드) 칸.
