# 신규 게임 점검·보완: PR #40 (대포 블록 부수기 · 미니 골프 · 볼링)

브랜치 `improve/newgames-40` (원 브랜치 `claude/new-games-physics` 위). 이번엔 1단계(버그·막힘·조작·난이도)만.

## 대포 블록 부수기 `cannon`
- 현재 상태: 조준 예상선, 공 여러 개 연사, 빨리 감기(7초 넘으면 자동), 수평 왕복 방지(세로 속도 최소값) 모두 있음. 진행 막힘 없음.
- 점검 결과: 줄마다 +1 아이템 칸이 있어 막힌 줄이 생기지 않음, 닫힌 공간에 공이 갇혀도 블록 체력이 줄어 결국 풀림. 터치(끌어 조준·떼면 발사, 아래쪽에서 떼면 취소)·키보드(←→ Space, X 빨리 감기) 모두 끝까지 가능.
- 고친 것: 없음.
- 가로 화면: **세로 유지**(블록이 위에서 한 줄씩 내려오는 구조).
- 남은 제안: 공 한꺼번에 회수 버튼, 10턴마다 보스 블록.

## 미니 골프 `golf`
- 현재 상태: 코스 20개 중 9홀, 좌우 뒤집기, 물·모래·경사·풍차·순간이동. 20개 코스 모두 지나갈 길이 있음(벽으로 막힌 "순간이동" 홀은 IN→OUT으로만 통과, 의도대로).

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 중 | `render(c, t)`의 t를 시간으로 썼지만 엔진은 프레임 간격(dt)을 넘김 → 물결·경사 화살표·깃발 펄럭임·조준 고리·첫 안내 깜빡임이 사실상 멈춰 있었음 |

- 고친 것: 그리기에서 `S.time` 사용.
- 가로 화면: **세로 유지**(코스가 세로로 긴 그림).
- 남은 제안: 홀 미리보기(카메라 한 바퀴), 되돌리기 없는 대신 "다시 치기 1회".

## 볼링 `bowling`
- 현재 상태: 정식 10프레임 점수(스트라이크·스페어·10프레임 보너스) 계산 정상, 굴리기 9초 넘으면 강제 정리로 막힘 없음.

| 분류 | 우선 | 내용 |
|---|---|---|
| 버그 | 중 | 골프와 같은 `render(c, t)` 문제로 첫 안내 깜빡임이 멈춰 있었음 |
| 조작 | 하 | 키보드로 Space를 누른 채 일시정지하면 세기 충전이 이어질 수 있음(창 전환 때는 풀림) |

- 고친 것: 그리기에서 `S.time` 사용.
- 가로 화면: **세로 유지**(레인 원근 그림).
- 남은 제안: 핀 액션 다시 보기, 연습 모드.
